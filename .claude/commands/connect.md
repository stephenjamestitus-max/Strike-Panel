# /connect

Connect a new social media platform to Zernio.

## Usage
```
/connect tiktok
/connect x
/connect linkedin
/connect facebook
/connect status
```

## Instructions

### /connect status
Use Zernio MCP tools to list all currently connected platforms.
Show: platform name, account handle, connection status, last active.

### /connect [platform]
Guide the user step by step through connecting the platform to Zernio:

**TikTok:**
1. Go to Zernio dashboard → Channels → Add Channel → TikTok
2. Log in with your TikTok account
3. Approve the permissions
4. Confirm connection via Zernio MCP

**X (Twitter):**
1. Go to Zernio dashboard → Channels → Add Channel → X/Twitter
2. Authorize with your @strikepanel account
3. Confirm connection via Zernio MCP

**LinkedIn:**
1. Go to Zernio dashboard → Channels → Add Channel → LinkedIn
2. Log in with your LinkedIn account
3. Select the strikepanel page if it exists, or personal profile
4. Confirm connection via Zernio MCP

**Facebook:**
Note: Personal account has ad restrictions but organic posting
should still work. Use corepanelv1@gmail.com account.
1. Go to Zernio dashboard → Channels → Add Channel → Facebook
2. Log in with corepanelv1@gmail.com
3. Select the strikepanel page (ID: 1075215372349968)
4. Confirm connection via Zernio MCP

After connecting — confirm which platforms are now active
and suggest running /schedule to queue up first week of content.
